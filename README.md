# Student Directory — React + Bootstrap

A responsive Student Directory built with React, Vite, and Bootstrap 5. It includes reusable components and props, search, student cards, add/delete actions, profile details, pagination, a dismissible alert, and footer.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually http://localhost:5173.

## Main files

- `src/App.jsx` — app state and component composition
- `src/data/students.js` — sample student records (edit names here)
- `src/components/` — Navbar, Breadcrumb, StudentCard, Pagination, SuccessAlert, Footer
- `src/App.css` and `src/index.css` — layout and styles
